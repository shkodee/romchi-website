## 2. Как устроено приложение (для сайта и тестов)
- **Главная:** баннеры партнёров (ARTPLAST, ALUSEL, STROFER), Заказы, Цены товаров, Дилеры и магазины, Компания, Склад, Новый заказ, «Незавершённый заказ», лента черновиков, Xizmatlar. Баланс звёзд в шапке.
- **Меню:** логотип компании, срок Premium, Профиль, Язык, Платежи, Промокод, Связаться, Настройки (Устройства — вход по QR, размер цифр на чертеже), Ночной режим, Сообщить о проблеме, «Пригласите и получите бонус», Выход.
- **Новый заказ:** Окна / Двери / Арки → конструктор, сохранённые и готовые фасоны (окна ~20, арки 12).
- **Редактор:** импосты (вертикальный, горизонтальный, двойной; тип Средний / Штульп, по внутренней / внешней ширине), 7 типов открывания, декор-шотланка (Стандарт, большой/средний/маленький цветок; тонкая/толстая; золотой/стандарт), заполнение (панели, сэндвич), фурнитура/двери, отмена/повтор, размеры через цифровую клавиатуру, кружки для деления секций.
- **Настройки изделия (⚙):** Алюминий / Пластик / Термо; партнёр-стекольщик; стеклопакет одно-/двухслойный + цвет стекла; бренд и серия (напр. Akfa 6000 QVT); балкон, металл 1 / 1.2 мм; тип рамочного профиля (Угловой); ламинация (Белый, Золотой дуб, Мокко, Антрацит + все цвета) или «внешний/внутренний»; подоконник по брендам 0–40 см + своё значение ±; «Сохранить шаблон».
- **Заказ:** кол-во, площадь, цена в so'm и $, примечание (голосом), «Другие варианты — Сравнить»; расчёт so'm/USD, скидка, аванс, клиент (имя, +998), Адрес, Срок.
- **Дилеры:** категории Аркачи, Ойначи + бренды (Alta Plast, Vitrage, Akfa, Ekopen, Neom, Rossen, CRAF, Alpro, Artplast, Alubest, Biko, Retpen, Lega, Tayhu, Alutex, WINDO…); список с расстоянием, звонком, маршрутом и карта.
