# Сайт Romchi для покупателей — общий план

Этот документ — главный план. Каждое направление (дизайн, фронтенд, бэкенд, тесты, 3D/AR) ведётся отдельно, и каждое опирается на этот файл.

## 1. Цель
Сайт для обычных людей и мастеров:
1. За 5 секунд понять, что такое Romchi («Romchi — sizga yordamchi»).
2. Увидеть, из чего состоит программа: скриншоты, видео, функции.
3. **Попробовать самому** на готовых образцах прямо на сайте, без скачивания.
4. Скачать приложение (App Store / Google Play) или оставить заявку.
5. Последний этап: 3D + AR через камеру — поставить окно или дверь у себя в комнате.

Язык: узбекский (латиница), потом русский.

## 2. Требования к дизайну
- Уникальный, современный, «премиальный», не шаблон.
- Много анимаций: появление при скролле, плавный скролл, 3D-модели окон и дверей в hero и в секциях (декоративные, крутятся и открываются при скролле).
- Mobile-first: большая часть трафика с телефонов и из браузера Telegram.
- Быстрый, несмотря на анимации; уважать `prefers-reduced-motion`.
- Важно: декоративные 3D-анимации делаем вместе с дизайном и фронтендом. AR через камеру — отдельный последний этап.

## 3. Структура сайта (секции)
1. **Hero**: слоган, короткое описание, кнопки сторов, большое 3D-окно (створки открываются при скролле).
2. **Что умеет Romchi**: 6–8 карточек (проектирование, расчёт цены в сумах/$, профили Akfa/Imzo/Alutex, раскрой, себестоимость и прибыль, склад, PDF клиенту, 3D).
3. **Как это работает**: 3 шага (нарисовал → посчитал → отправил клиенту).
4. **Sinab ko'ring (Попробуйте сами)**: интерактивная демо-версия, см. п. 4.
5. **Скриншоты**: карусель экранов в рамках телефонов.
6. **Примеры / галерея**: готовые изделия (окна, балконные блоки, двери, арки; ПВХ и алюминий).
7. **Видео-демо** (30–60 сек).
8. **Для кого**: мастера / компании / дилеры.
9. **Premium**: что бесплатно, что платно.
10. **FAQ**.
11. **Контакты / заявка**: форма, Telegram, телефон.
12. (Последний этап) **3D + AR**: «Ko'rish xonangizda».

## 4. «Sinab ko'ring» — попробовать образцы
Мини-версия редактора в браузере на демо-данных, без регистрации:
- Выбрать образец из 6–10 шаблонов (окно 1/2/3 створки, балконный блок, дверь, арка).
- Поменять ширину и высоту, тип створок (поворотная / откидная / глухая), профиль (Akfa / Imzo / Alutex), цвет.
- Сразу увидеть чертёж с размерами (2D SVG), примерную цену (сум / $) с разбивкой, мини-схему раскроя с % эффективности.
- Кнопка «Получить PDF» (пример расчёта) и CTA «Скачайте приложение, чтобы сохранить заказ».
- Сравнение 2–3 образцов рядом (цена, размеры).
- Цены демо и примерные, это нужно подписать на сайте.

Вопрос к команде приложения: можно ли взять формулы расчёта и шаблоны из приложения (JSON), чтобы демо считало так же, как Romchi.

## 5. Анимации
Придумываем в дизайне, программируем во фронтенде.

| Где | Что |
|---|---|
| Hero | 3D-окно крутится, створки открываются при скролле |
| Что умеет | Карточки появляются по очереди |
| Как это работает | 3 шага переключаются при скролле, секция закреплена (pin) |
| Скриншоты | Телефон с экранами слегка поворачивается в 3D |
| Sinab ko'ring | Чертёж и цена плавно меняются при изменении размеров |
| Галерея | Превью оживают при наведении / касании |

Инструменты: GSAP + ScrollTrigger (скролл), Lenis (плавный скролл), Framer Motion (UI), React Three Fiber (3D).
Декоративные 3D-окна строим прямо в коде (рама, створки, стекло) — отдельные файлы моделей не нужны. Файлы GLB/USDZ нужны только для AR (последний этап).
Облегчённая версия для слабых телефонов; без анимаций при `prefers-reduced-motion`.

## 6. Рекомендации
- **Демо как главный крючок**: человек сам «пощупал» программу, и тогда кнопка скачать работает лучше.
- **Telegram**: кнопка «Написать в Telegram» и заявки в Telegram-бот. Обязательно тестировать в Telegram-браузере.
- **Отзывы мастеров** (только реальные, с разрешения) и счётчик пользователей, если есть реальные цифры.
- **Ссылка-поделиться**: расчёт из демо можно отправить ссылкой.
- **SEO** на узбекском: «deraza narxi», «plastik deraza hisoblash», «alyumin eshik» и т. п.
- **Аналитика событий**: открыл демо, поменял размер, скачал PDF, нажал «скачать приложение».

## 7. Технологии (предложение)
- Next.js (React) + TypeScript + Tailwind CSS
- Анимации: GSAP + ScrollTrigger, Lenis, Framer Motion
- 3D: three.js через React Three Fiber + drei
- AR (последний этап): Google `<model-viewer>` (Android: Scene Viewer, iPhone: Quick Look с USDZ; Safari на iOS не поддерживает WebXR)
- Бэкенд: Node.js (NestJS или Next.js API) + PostgreSQL, headless CMS (Strapi / Directus) для примеров и FAQ
- Хостинг: Vercel или свой сервер + CDN для моделей и картинок

## 8. Разделение работы

### 1 — Дизайн
- Мудборд, фирменный стиль сайта (цвета, шрифты, 3D-стиль)
- Макеты всех секций: десктоп + мобильная версия
- Дизайн «Sinab ko'ring» (выбор образца, ползунки размеров, чертёж, цена, раскрой)
- Описание анимаций: что и как двигается
- Скриншоты в рамках телефонов, иконки, превью образцов

### 2 — Фронтенд
- Проект Next.js, вёрстка по макетам, адаптив
- Анимации (GSAP, Lenis), декоративные 3D-сцены (R3F)
- Демо-калькулятор: чертёж SVG, расчёт, раскрой, PDF
- Языки uz/ru, SEO, скорость (Lighthouse 90+ на мобильном)

### 3 — Бэкенд
- API: образцы/шаблоны, цены профилей (демо), галерея, FAQ
- Форма заявки → БД + Telegram-бот
- CMS/админка, хранилище файлов, ссылки «поделиться расчётом»
- Аналитика

### 4 — Тестирование
- Чек-листы и тест-кейсы по всем секциям и демо
- Проверка расчётов демо против приложения
- Устройства: iPhone, Samsung, Xiaomi; браузеры Chrome, Safari, Telegram
- Скорость, доступность, формы, ссылки

### 5 — 3D + AR (последний этап)
- Модели образцов (экспорт из Romchi 3D или Blender) → GLB + USDZ, реальный масштаб
- `<model-viewer>` с AR, QR-код для ПК
- Тест AR на устройствах

## 9. Порядок
