## 1. Новая цель
- Трафик: реклама в Instagram → ссылка → сайт. Открывается во встроенном браузере Instagram на телефоне.
- **Первые 5–6 секунд решают всё**: человек должен сразу понять «здесь я посчитаю своё окно» и начать.
- Сайт **не информационный**. Сразу открывается «Sinab koʻring»: выбрать тип → ввести размер → выбрать вариант → увидеть цену → оставить заявку.
- Аудитория: обычные граждане, не мастера. Никаких терминов (раскрой, импост, эффективность, бренд профиля в первом шаге).

## 2. Путь пользователя (mobile-first)
| Шаг | Экран | Правила |
|---|---|---|
| 0 (0–5 сек) | Заголовок-вопрос «Qanday deraza kerak?» + 6 больших карточек-картинок | Виден сразу, без ожидания анимации и JS. Совпадает с картинкой/фразой рекламы |
| 1 | Тип: 1 / 2 / 3 tabaqali, Balkon bloki, Eshik, Arka | Один тап → следующий шаг |
| 2 | Размер: 2 больших поля **в сантиметрах**, цифровая клавиатура | Подсказка «Qanday oʻlchash kerak?» (анимация) |
| 3 | Цвет (кружки) + профиль/уровень | Профили — только реальные бренды из romchi.uz (см. п. 4), без Imzo |
| Итог | Примерная общая цена (только итог, без разбивки), картинка/3D окна | Главная кнопка: «Ustalarga yuborish» (отправить мастерам) |
| 4. Локация | Viloyat / shahar → tuman (например: Toshkent shahri → Shayxontohur tumani) | Два простых списка с поиском; можно «Joylashuvimni aniqlash» (геолокация) |
| 5. Мастера | Список мастеров, которые работают в этом районе | Карточка мастера: имя/компания, район, (рейтинг, фото работ — если есть реальные данные) |
| 6. Отправка | Человек выбирает 1 или нескольких мастеров и отправляет макет + свой телефон | Мастер получает макет (чертёж, размеры, цвет, профиль) и отвечает **примерной ценой** |
| 7. Ответ | Человек получает цены от мастеров | Канал ответа — открытый вопрос (SMS / Telegram / страница заявки по ссылке) |

Прогресс 1-2-3 сверху, кнопка «Orqaga», состояние в URL (можно поделиться).

## 2.1 Поток «макет → мастера» (главная новая функция)
```
Гражданин: макет окна → район → список мастеров → отправить макет (+ телефон)
                                                        │
Бэкенд: заявка (макет JSON + чертёж + район + телефон) ─┤→ мастерам района
                                                        │
Мастер (приложение Romchi / Telegram-бот): видит макет → пишет примерную цену
                                                        │
Гражданин: получает ответы мастеров → звонит / выбирает
```

- **Бэкенд**: заявки, рассылка мастерам, ответы с ценой, уведомления.
- **Сайт**: шаги 4–7, страница заявки «Ваши ответы» по ссылке.
- Защита от спама: подтверждение телефона (SMS-код) перед отправкой.
