## Platform

web

## Users
Обычные граждане Узбекистана (не мастера), которые хотят поставить или заменить окно, балконный блок, дверь или арку. Приходят из рекламы в Instagram, открывают сайт во встроенном браузере Instagram (часто Telegram) на телефоне. За первые 5–6 секунд должны понять: «здесь я сам посчитаю своё окно» — и начать.

Вторая аудитория — мастера и компании (пользователи приложения Romchi): для них старая главная уходит на `/ustalar/`, ссылка в подвале «Siz ustamisiz?».

## Product Purpose
Сайт-конструктор: выбрать тип изделия → ввести размер (в сантиметрах) → выбрать цвет и профиль → увидеть примерную общую цену → выбрать регион и туман → выбрать мастеров района → отправить им макет и свой телефон. Мастер отвечает примерной ценой. В конце — экран «Maketingiz tayyor» и переход в приложение Romchi (App Store / Google Play).

Успех: человек дошёл до отправки макета мастерам (событие `Lead`), а затем установил приложение.

## Positioning
Цену считает тот же движок, что у мастеров в приложении Romchi (по romchi.uz: 10 000+ активных пользователей, 500 000+ расчётов), а макет уходит не «в колл-центр», а реальным мастерам именно твоего района, которые отвечают ценой. Человек видит своё окно на чертеже (с размерами, створками, цветом с реальной текстурой) ещё до звонка.

## Operating Context
- Телефон, встроенный браузер Instagram/Telegram, мобильный интернет, одна рука.
- Человек обычно стоит перед своим проёмом с рулеткой.
- Язык: узбекский (латиница) по умолчанию, переключатель на русский.
- Термины мастеров (раскрой, импост, эффективность) для граждан скрыты.

## Capabilities and Constraints
- Типы: 1 tabaqali, 2 tabaqali, 3 tabaqali, Balkon bloki, Eshik, Arka.
- Размер: поле + ползунок, в сантиметрах. Размеры на чертеже нажимаются; кружки на концах размерных линий делят секции поровну. Тип открывания меняется нажатием на стекло.
- 18 цветов профиля (Oq + 17 из приложения) с реальными текстурами (`web/public/colors/c01–c17.webp`). Цвет №4 — название уточняется.
- Профиль: сначала выбирается **уровень** (Ekonom / Standart / Premium); внутри уровня человек может сам выбрать бренд — бренды не принижаются, показываются логотипами с romchi.uz. Только бренды romchi.uz, **без Imzo**. (Решение временное, может измениться.)
- Цена: только общая, округлённая, без разбивки и без $. Демо-цены помечаются как примерные.
- Регион → туман по официальному SOATO (14 регионов, 209 районов).
- Мастера: пока демо-карточки «Namuna usta», явно помеченные. Без API ничего не отправляется.
- PDF и «Ulashish» (ссылка) — есть.
- Скрыть для граждан: раскрой, «Samaradorlik», сравнение, разбивку цены.
- Первый экран рендерится без JS-анимации; в браузере Instagram — без Lenis, 3D только после выбора.
- Открыто: реальные цены, база мастеров, канал ответа мастеров (SMS / Telegram / ссылка), подтверждение телефона SMS-кодом, Meta Pixel ID, домен.

## Product Principles
1. Один экран — одно решение. Никаких терминов мастеров.
2. Своё окно видно сразу: чертёж реагирует на каждое касание.
3. Честность: цена «taxminiy», демо-мастера помечены, данные телефона — только выбранным мастерам.
4. Быстро в Instagram-браузере: первый экран без ожидания.
5. Цель — макет у мастеров района, затем приложение.

## Accessibility & Inclusion
Люди всех возрастов, включая старших: крупные цели нажатия (≥ 48 px), базовый текст ≥ 16 px, контраст 4.5:1, цифровая клавиатура для размеров, `prefers-reduced-motion`.
